# save：回填问答成果

把对话中有价值的内容沉淀为知识库页面，使结果复利。页面类型与 frontmatter 模板见 `CLAUDE.md`。

**步骤：**

1. **判断类型**：
   - **跨源综合**（综合多个来源的比较、结论）→ `知识库/综合/`（`type: synthesis`）
   - **单次问答**（基于知识库回答的一个问题）→ `知识库/输出/`（`type: output`）
2. 从内容中提炼精简中文标题作文件名（去掉营销词与副标题，文件名即标题）。
3. 创建页面：使用对应模板，填写完整 frontmatter（含 `tldr`、`sources`、`related`），正文整理为**结构化的知识库内容，不是聊天记录的复制**。`related` 等可选字段只在关系确实存在时填，不为凑字段而填。
4. 维护交叉引用：在相关页面的 `related` 字段中加入新页面；在 `知识库/索引.md` 添加条目（链接 + `tldr`）。
5. 追加 `知识库/操作日志.md`：`## [YYYY-MM-DD] save | 标题`

**质量检查：**

- [ ] 内容已结构化为知识库格式（标题、列表、表格），不是原始聊天记录
- [ ] 所有关键论断有 `[[]]` 引用
- [ ] frontmatter 完整（含 `tldr`）
- [ ] `索引.md` 与 `操作日志.md` 已更新
