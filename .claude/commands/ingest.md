# ingest：摄取原始资料

将 `原始资料/` 中的新来源编译为 `知识库/` 页面。规则层约定（页面类型、frontmatter 字段、命名规范、核心原则）见 `CLAUDE.md`，此处只写操作步骤，不重复其规则。

**步骤：**

1. 查 `知识库/操作日志.md`，确认哪些原始资料尚未被 ingest（日志中已有 ingest 记录的跳过）。可用 `grep "^## \[" "知识库/操作日志.md"` 快速检索既往记录。
2. 扫描 `原始资料/剪藏/`、`原始资料/截图笔记/`、`原始资料/古籍/` 查找待处理文件。
3. 确定 ingest 单元：用户明确指定的文件优先；否则单个文件为一个单元，一批 1–5 个。
4. 完整阅读来源全文。
5. **与用户讨论关键发现，确认本次想强调什么方向**——方向由用户判断，LLM 不代劳。
6. 在 `知识库/摘要/` 创建摘要页（`type: source`）：填写完整 frontmatter（含 `tldr`、`raw`），正文按 `CLAUDE.md` 摘要页规范（第五章第 1 条）的结构撰写：一句话主旨 → 关键论点（3–7 条）→ 与其他资料的关系 → 值得追问的问题，列出可抽取的概念与实体（带 `[[]]`），标注与现有页面的连接。
7. 创建/更新概念页与实体页（`知识库/概念/`、`知识库/实体/`）：**2+ 来源 → 完整页；首次出现 → `status: stub` 的 stub 页**（正文只写定义与出处，等第二来源出现再扩写）。
8. 维护交叉引用：更新相关页面的 `sources`／`related` 字段，确保无 dangling wikilink。正文行内 `[[]]` 与 frontmatter 链接字段双份维护，两边都不能偷懒。
9. 更新 `知识库/索引.md`：添加新条目（链接 + `tldr`）。
10. 追加 `知识库/操作日志.md`：

```markdown
## [YYYY-MM-DD] ingest | 标题
- 处理：[[摘要/xxx]]
- 原始资料：原始资料/剪藏/xxx.md
```

**质量检查：**

- [ ] 所有新页面含完整 frontmatter（含 `tldr`）
- [ ] 所有 `[[]]` 链接指向已存在的页面（无 dangling）
- [ ] 摘要页含反方观点或数据缺口（如适用）
- [ ] `索引.md` 与 `操作日志.md` 已更新
- [ ] **`原始资料/` 下文件未被修改**（不移动、不改名、不改内容）

**重要约束：**

- `原始资料/` **完全不可变**，不修改、不移动、不重命名
- 处理状态只由 `操作日志.md` 追踪，不在 `原始资料/` 层面做任何标记
- `raw` 字段须含完整子目录路径，如 `[[原始资料/剪藏/filename]]`；没有对应本地文件的（只有线上视频或网页）直接写原始 URL 字符串
- 来源没说的内容不要用通用知识补全；写明"现有来源未覆盖"
- wiki 内部链接一律写全路径（`[[摘要/xxx]]`），概念页之间可写短链（`[[清结算]]`）
