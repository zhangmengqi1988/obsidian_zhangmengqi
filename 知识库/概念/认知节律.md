# 认知节律

**定义**：人的警觉性、工作记忆与执行功能等认知绩效由内源性昼夜节律（circadian clock）驱动，在一日内呈波浪形起伏：多数人警觉性在觉醒后数小时进入高峰、午后有明显低谷（post-lunch dip）。个体峰值时段由 chronotype（晨型/夜型）决定。

## 出处与证据

- 源自 [[摘要/精力复利]]（第 3 点"守护黄金时段"）：主张把最难、最重要、需深度思考的事放在精力峰值做，而非谷底，同样投入 8 小时产出可差三四倍。
- 可核查内核来自 [[摘要/昼夜节律对认知绩效的影响]]（Dijk & von Schantz 2005）：确认认知绩效随昼夜相位波动、chronotype 决定个体峰值时段。
- **限定**：相关实证研究并非"哈佛"专属（Dijk 属波士顿布莱根妇女医院、Schmidt/Cajochen 属日内瓦等机构）；**"产出差 3-4 倍"查无出处**，属 [[摘要/精力复利]] 的话术数值，本页不采信该量化。

## 关键含义

- "认知峰值普遍在上午"是**流行化的泛化**，对夜型（chronotype 偏晚）个体不成立——个体应识别自己的 chronotype 再安排任务。
- 操作建议（把高认知负荷任务放到个人峰值时段）有节律基础，价值成立；但"3-4 倍产出差"需降级为不确定的量级。

## 与其他概念的关系

- 与 [[高杠杆任务]] 结合：高影响 + 个人峰值时段 = 把最好的精力投到最能改变结果的事上。
- 与 [[身体地基]] 相关：昼夜节律受睡眠-光线驱动，睡眠质量直接影响相位与峰值幅度。

## 待解问题

- 节律相关性是否等于"按时段调任务能显著提效"的干预有效性？直接因果证据仍有限。
- 久坐、人造光、屏幕如何扰动个体昼夜相位？现有来源未覆盖。
