## 摘要
- [[摘要/清结算模块设计]] —— 交易完成之后的资金链路：清分/计费/结算的六问三原则与五层架构，必须跟随业务形态，对账对平是底线
- [[摘要/支付系统技术决策]] —— 渠道一渠道一微服务、网关收敛终端适配、Redis Hash 加分布式锁保回调幂等，三个决策共同防止局部故障拖垮支付系统
- [[摘要/跨库 Join 方案]] —— 绑定表、广播表、冗余字段、应用层关联、数据异构五种关联方案的代价对比与强一致到最终一致的能力阶梯；没有银弹，按规模选型
- [[摘要/MIT 6.824 分布式系统]] —— MIT 分布式课导论讲义：以性能与容错为主线，并发带来的复杂性与部分失败是固有挑战，千台机器不保证千倍加速
- [[摘要/如何构建 LLM Wiki]] —— LLM Wiki 搭建三步：建 raw/wiki 目录骨架、写 CLAUDE.md 立规矩、配 ingest 等四个命令
- [[摘要/DDD 分层到六边形架构]] —— DDD 战略设计划边界、战术设计建模型，六边形与整洁架构约束依赖只能向内；复杂在领域时才值得上
- [[摘要/Spring Boot 自动装配原理]] —— Spring Boot 自动装配四步：加载候选、去重、条件过滤、拓扑排序；约定大于配置、用户 Bean 优先
- [[摘要/Spring Boot Starter 全解析]] —— Starter 是依赖描述符加自动配置代码的封装；依赖与配置分离，靠条件装配与属性绑定做到一次封装处处可用
- [[摘要/Spring Boot 4 API 版本控制]] —— Spring Boot 4 起 API 版本控制原生支持：Header 声明版本 + 方法级 version 属性
- [[摘要/美团数据库容量评估系统]] —— 录制线上 SQL 流量回放到沙盒，用倍速回放探测集群 QPS 上限，再把评估结果接进容量运营闭环
- [[摘要/道氏理论1]] —— 道氏理论第一讲：平均价格指数消融一切、主要趋势不可被操纵，是一切技术分析的哲学基石

## 概念
- [[清结算]] —— 清算/清分/结算的概念边界与完整资金链路，六问三原则、五层七步架构、状态机与对账底线
- [[支付网关]] —— 交易阶段的三个架构决策：渠道隔离、终端适配收敛、回调一致性做法与未解决的降级问题
- [[跨库 Join]] —— 分库分表后关联查询的五方案代价表、一致性阶梯、数据异构适用门槛与对账兜底
- [[分库分表]] —— 目前仅覆盖分片键粘性与规模选型等间接约束；拆分策略、扩容、全局 ID 为已登记的来源空白
- [[LLM Wiki]] —— LLM 担任 wiki 维护者、把原始资料编译成双链知识库的三层范式
- [[自动装配]] —— Spring Boot 按条件注册 Bean 的四步链路：加载候选、去重、条件过滤、拓扑排序；用户 Bean 优先
- [[Starter]] —— 把依赖描述符与自动配置代码打包成可复用模块；靠条件装配与属性绑定做到用户可覆盖、一次封装处处可用
- [[条件注解]] —— 自动装配的开关：条件之间取 AND，classpath 有无与容器内有无是两条独立判据
- [[DDD]] —— 领域驱动设计：战略设计划边界、战术设计建模型；复杂在领域时才值得上，简单在数据表时别过度设计
- [[限界上下文]] —— 模型的适用范围：同一术语在不同上下文含义可以不同，它是模型边界而非部署边界
- [[六边形架构]] —— 与洋葱、整洁架构共享「源码依赖向内」纪律；判断落地的标准是改数据库时领域测试是否几乎不用改
- [[API 版本控制]] —— 同一路径靠声明区分接口版本；DTO 分版本、Service 不跟版本走，默认版本用来留迁移窗口
- [[流量回放]] —— 录制线上真实 SQL 到隔离沙盒重放，用 1 倍速验证变更效果；主库按事务聚合、从库按单条 SQL
- [[容量评估]] —— 用倍速回放探测集群 QPS 上限，再以水位（线上 QPS/上限）做周期性容量运营与保鲜重评
- [[道氏理论]] —— 查尔斯·道创立的技术分析基石：平均价格指数消融一切、主要趋势不可被操纵
- [[三种运动]] —— 道氏理论将股价运动分为主要趋势、次级趋势、日间波动三级
- [[平均价格指数消融一切]] —— 道氏理论逻辑基础：价格已反映所有参与者意愿与已知信息，甚至部分反应未来
- [[能级]] —— 讲师自创概念：个股→板块→大盘是环环相扣的能量场，高一级压制低一级
- [[预期差]] —— 大众认知与股价走势之间的差值，预期差越大未来价格空间越大
- [[反身性]] —— 索罗斯提出的价格与认知正反馈循环：价格影响认知，认知又影响价格
- [[穷变通久]] —— 讲师引自易经的周期论：穷尽→转折→主升→极盛，周期必完整
- [[水位]] —— 讲师对投融资关系的比喻：投资进水大于融资出水则牛市，反之则熊市
